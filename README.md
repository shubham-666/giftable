# Python Assignments — User Input Solutions

All programs are beginner-friendly and ask the user for input where suitable. Run each `.py` file separately with Python 3.

## Run a program
```bash
python A1_greatest_of_four.py
```

## Contents
- A1: own name, greatest of four numbers, ticket price, electricity bill slabs
- A2: digit census, prime check, multiplication grid, largest/second-largest, Collatz, GCD
- A3: cities list, favourite items, ten marks, vowel count, palindrome
- A4: pass/fail list comprehension
- A5a: Bank class
- A5b: Book and Library classes
- A6: text, CSV (`DictWriter`/`DictReader`), and JSON (`dump`/`load`)
- A7: Student class with private marks, file handling, exception handling, output-prediction practice
- A8: Missing Fest Trophy text adventure with failed and winning routes
- A9: Mini Library System with JSON save/load, CSV export, text reader, exceptions, and `check.py`

## Notes
- The ticket-price and electricity-bill slabs are not specified in the provided brief, so the programs clearly label their example slab rates. Change them if your teacher provided different rates.
- The pasted A2 brief omits the names of two of the six compulsory Part A tasks. The named tasks are included, along with common loop practice. Confirm the two missing task titles against your class sheet.
- `A9_Mini_Library/AI_USAGE.md` is included as a template. Edit it honestly to describe how you used AI and what you changed/understood.
