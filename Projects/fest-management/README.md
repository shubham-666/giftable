# Fest Management

A responsive campus fest schedule with create, read, update, and delete operations.

## Run

Open `index.html` in a modern browser. No packages, build step, or server are required.

## Features

- Add, edit, search, and delete events.
- Validate event details, dates, and guest capacity.
- View live totals for upcoming events, live events, and guest capacity.
- Keep records in this browser using `localStorage`.
- Adapt the schedule and editor for mobile and desktop screens.

Data stays in the browser used to open the app; it is not shared with other devices.

## Publish as its own GitHub repository

Create an empty GitHub repository named `fest-management`, then run these commands from this folder:

```powershell
git remote add origin https://github.com/YOUR-USERNAME/fest-management.git
git add .
git commit -m "Build campus fest CRUD app"
git push -u origin main
```
