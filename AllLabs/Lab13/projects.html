Mini Library System

A small command-line program for keeping track of books

I built this project to practise Python classes, methods, dictionaries, and working with files. The section below is a small JavaScript demo of adding, borrowing, and returning books; the original Python program runs in the terminal.

What it can do

  • Add a book with its title, author, and number of copies.
  • Show the books currently stored in the program.
  • Borrow a copy when one is available, or return a borrowed copy.
  • Save the book list to library.json and load it again later.
  • Export the current book list as library.csv.
  • Read and display the contents of a text file.

Try the browser demo

Add a title and author, then use the buttons on a book card. This demo keeps its list in memory, so refreshing the page starts a new list. The Python program separately saves and loads JSON files.

How the code is organised

Book class: Each book object stores its title, author, and available-copy count. The copy count is private, and the borrow() method reduces it only when a copy is available. Returning a book adds one to the available count; the program does not keep a separate record of individual loans.

Library class: The library keeps book objects in a dictionary. It uses a lower-case, trimmed title as the lookup key, so searching for a title is not affected by its letter case.

main.py: A menu asks which operation to perform and calls the matching library method. Invalid number input and file-operation errors are caught and shown to the user.

What I learned

I learned how to split a program between classes, use methods to protect and update an object's data, and keep information after a program closes by writing it to a file. JSON stores the book records in a format Python can load again; CSV puts the records into rows that spreadsheet programs can open.

The project also taught me to check important edge cases: a book might not exist, there might be no copies available, or a file might be missing or have invalid JSON.

Try it in Python
